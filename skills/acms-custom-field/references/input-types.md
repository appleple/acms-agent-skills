# 入力の種類の選び方

カスタムフィールドメーカーの種類は、テキスト（一行）・テキスト（複数行：テキストエリア / ブロックエディター / ライトエディター / テーブル）・選択（チェックボックス / セレクトボックス / ラジオボタン）・アップロード（メディア / 画像 / ファイル）に分かれる。迷いやすいのはアップロードと複数行テキストの2つ。

## メディアと、画像・ファイル（archives）

| | メディア | 画像・ファイル（archives） |
|---|---|---|
| フィールドに保存するもの | メディアの ID（`name@media`） | ファイルのパスと、アップロード時の情報（`@path`・`@x`・`@y`・`@alt` など） |
| ファイルの置き場所 | メディア管理（画像は media、ファイルは storage） | archives |
| 同じファイルを別の場所で使う | メディア管理から選ぶだけ。再アップロードしない | 使うたびにアップロードする |
| 差し替え・代替テキスト・キャプションの修正 | メディア管理で直すと、そのメディアを使う全フィールドの表示が変わる（表示時にメディアの情報を読み込むため） | フィールドごとに入力し直す |
| 画像の比率 | `@ratio`・`@width`・`@height` が使える（メディアに保存された寸法から計算） | `@ratio` は無い。`@x`・`@y`（保存された画像の寸法）か、`imageRatioSizeH` でファイルから求める |
| 焦点（フォーカルポイント） | `@focalX`・`@focalY` が使える | 無い |
| ファイルのダウンロード | ダウンロード用のリンクになり、メディアごとに公開範囲（公開・エントリーに従う・ログインユーザーのみ・非公開）を設定できる | archives の静的なファイルとして誰でも取得できる |
| アップロード時のサイズ違い | — | フィールドの設定で normal・tiny・large・square を作れる |

メディアを選ぶ。理由は上の表の「差し替え・修正が全箇所に反映される」「`@ratio` で高さを計算できる」「ファイルの公開範囲を設定できる」の3つ。次の点は利用者に伝える。

- メディア管理を使うには、コンフィグの機能設定で「メディア管理」が有効であること（既定は有効）。
- メディア管理で画像を差し替える・代替テキストを変えると、そのメディアを使うすべての場所が変わる。ページごとに代替テキストを変えたいときは、テキストのフィールドを別に用意する。
- メディア管理でメディアを削除すると、フィールドには ID だけが残り、`path` などは空になる。出力側で `path` の有無を判定する（references/output.md）。

画像・ファイル（archives）を選ぶのは、メディア管理を無効にしているサイトや、既存のフィールドの形を変えられないときに限る。種類を後から変えると保存される値の形が変わり、出力側のテンプレートも書き直しになる。

## テキストエリア・ブロックエディター・ライトエディター

| | テキストエリア | ブロックエディター | ライトエディター |
|---|---|---|---|
| 保存されるもの | プレーンテキスト | HTML（見出し・段落・リスト・リンク・画像などのブロック） | HTML（インラインの装飾とリンク） |
| 出力時の処理 | なし | 本体が出力前に整形する（画像のリサイズ、埋め込みなどの機能ブロックの展開。管理画面では展開しない） | なし |
| 標準テンプレートでの出力 | `{name}[nl2br]`（エスケープしたうえで改行を `<br>` に） | `{name}[raw]` | `{name}[raw]` |
| 状態 | — | Ver. 3.2 から使える | Ver. 3.2 から、管理画面の JavaScript に非推奨と明記 |

- 装飾もリンクも要らないならテキストエリア。HTML をエスケープせずに出す必要がなく、安全に扱える。
- 見出しやリンク・画像を入れたいならブロックエディター。ライトエディターは新しく使わない。既存のライトエディターのフィールドを直すときは、置き換えるかどうかを利用者に確かめる。保存済みの値がブロックエディターでどう読み込まれるかは未確認なので、置き換えるなら既存の値で表示を確かめる。
- HTML を出力するときのエスケープの外し方（標準テンプレートの `[raw]`、Twig の `|safe_html` / `|raw`）は acms-template-acms / acms-template-twig の規則に従う。
- ブロックエディターで使えるブロックの設定やカスタマイズは <https://developer.a-blogcms.jp/document/units/block-editor.html> から辿る。

## 選択（チェックボックス・セレクトボックス・ラジオボタン）

- 複数選べるチェックボックスは `name[]` で送り、出力では標準テンプレートは `name:loop`、Twig は `fields.name.array` を回す。
- 値に `true` / `false` や数字を使うと、Twig では真偽値・数値に変換されて渡る（references/output.md）。
