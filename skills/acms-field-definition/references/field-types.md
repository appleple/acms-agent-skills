# フィールド型の選び方（Ver. 3.3 以降）

Ver. 3.3.0-alpha.1 のソースで確かめた内容。`【Pro】` はプロフェッショナル以上のエディションで使える型（スタンダードでは既にある定義が読み取り専用になり、値は残る）。

## 判断表

| 入れたいもの | 型 | 理由・注意 |
|---|---|---|
| 1 行の文字 | `text` | 文字数の表示・目安、前後の文字（prefix / suffix）を付けられる |
| 改行のある文字 | `textarea` | |
| 電話番号・メールアドレス・URL | `tel`・`email`・`url` | 型の検査が掛かる。`text` に入れて入力チェックを足すより確実 |
| 数値（価格・数量） | `number` | 小数の桁（`decimals` 0〜10）、単位を prefix / suffix で付ける。単位を値に含めない |
| 決まった選択肢から選ぶ | 1 つなら `select` か `radio`、複数なら `checkbox` | 保存・出力されるのは value。value は英数字にして後から変えない |
| 日付・時刻 | `date`・`time`・`datetime` | |
| 画像 | `media-image` | メディア管理の ID を参照する。差し替えや代替テキストの修正がすべての使用箇所に反映される |
| PDF などのファイル | `media-file` | |
| 複数の画像 | `media-gallery`【Pro】 | 出力は `キー@path:loop` のように派生キーまで書く |
| 他のエントリー・カテゴリー・ユーザー | 参照型（下記） | ID を `text` に入れない |
| 見出し・リスト・リンク・画像を含む本文 | `block-editor` | 出力は `{キー}[raw]`。設定はブロックエディターのフィールド単位の設定と同じ |
| 地図の位置 | `map`【Pro】 | |
| 画面に出さない固定値 | `hidden`【Pro】 | |
| 同じ組の項目を繰り返す（スペック表、FAQ） | `group` | 行数の上下限・重複の禁止を設定できる。繰り返しの中に繰り返しは置けない |
| 行ごとに違う組の項目を選ぶ（ブロックの並び） | `group` の `componentPerRow`【Pro】と `kind` | 行で選んだ種類は `<グループのキー>_kind` に保存される |
| 複数の対象で同じ項目の組を使い回す（住所、SEO） | `component`（対象 `component` で作り、`config.component` に code を書く） | 値のキーは `<項目のキー>_<中のキー>` に展開される。コンポーネントの中にコンポーネントは置けない |
| 入力欄の整理だけ（値を保存しない） | `heading`・`message`・`row`・`tabs`/`tab`・`accordion` | |
| アップロードしたファイルを直接持つ | `image`・`file`（アーカイブ） | ユーザーの定義でしか選べない。それ以外はメディア型を使う |

SEO の項目（メタタイトル・説明・robots・OGP 画像）は、管理画面のフィールドパターン「SEO」から挿入できる。既に同じキーの値がある項目は挿入されない。

## 参照型

`relation-entry`・`relation-entries`・`relation-category`・`relation-categories`・`relation-user`・`relation-users` の 6 つ。単数か複数かで分かれる。

- 選べる範囲を絞れる（エントリーはブログ・カテゴリー・状態、カテゴリーは親カテゴリー、ユーザーは権限）。運用者が選び間違えないよう、範囲は必ず絞る。
- 値は参照先の ID。表示時に参照先の値が補われる。

| 参照先 | 補われる値（標準テンプレートは `{キー@title}` の形） |
|---|---|
| エントリー | `@title`・`@code`・`@url`・`@permalink`・`@datetime`・`@categoryName`・`@eid`・`@bid`・`@cid`・`@uid` |
| カテゴリー | `@name`・`@code`・`@url`・`@cid`・`@bid` |
| ユーザー | `@name`・`@code`・`@icon`・`@uid` |

- 公開側で見えない参照先（非公開・期間外など）は、ID ごと出力から外れる。テンプレートで公開状態を判定しなくてよい。
- Twig（V2 モジュール）と JSON では、参照先のカスタムフィールドが `.fields` として 1 段だけ展開される（ユーザーは `outputFields` を有効にしたときだけ）。標準テンプレートでは参照先のカスタムフィールドは展開されない。参照先のカスタムフィールドが要るなら Twig で書くか、参照先を別のモジュールで読む。
- 参照と埋め込みの選び方: 参照先が単独でも意味を持ち、他からも参照される（著者、関連記事、店舗）なら参照型。その項目の中でしか意味を持たない（このエントリーだけの FAQ）なら `group` で埋め込む。

## 表示条件

- フィールドセットの表示条件: ブログ、カテゴリー・サブカテゴリー・エントリーのコード（エントリー）、親カテゴリー・カテゴリーのコード（カテゴリー）、親ブログ・ブログのコード（ブログ）、権限・ユーザーのコード（ユーザー）、モジュール名・モジュール ID（モジュール）で出し分ける。`axis: descendant-or-self` で子孫も含められる。
- 項目の条件付き表示: 同じセットの他の項目の値で出し分ける。隠れた項目の値は既定で残る（`clearOnHide` で消せる）。
- 権限ごとの表示（`config.visibility`。編集できる・読み取りだけ・出さない）は、サーバー側でも強制される。
