# 公式チュートリアルの題材に当てはめる例

公式チュートリアル（<https://developer.a-blogcms.jp/document/tutorial/>）は、標準テンプレート版（Step 1〜3）と Twig 版（第 1〜7 回）で、同じ静的サイト（15 ページ。CSS フレームワークと JavaScript のライブラリを CDN から読む）をテーマにする。この題材を渡されたときに、SKILL.md の手順がそれぞれ何を決めるかの例。チュートリアルの本文の代わりではないので、操作の細部はチュートリアルの各ページを読む。

| 手順 | この題材で決めること | チュートリアルの該当箇所 |
|---|---|---|
| 1. 環境 | バージョンを確かめる。チュートリアルは公式テーマを入れた新規インストールから始め、カテゴリーやフォーム ID の一部が既にある前提。別のテーマから始めるなら、それらを手順 7 で作ってもらう | 標準版 Step 1「動作環境を用意します」、Twig 版第 1 回 |
| 2. 標準か Twig か | 利用者に選んでもらう。標準なら Step 1〜3、Twig なら第 1〜7 回が対応する | 両版の目次 |
| 3. 調べる | inventory.sh で、トップ・お知らせの一覧と詳細・一覧の 2 ページ目・サービスの一覧と詳細・お問い合わせの入力 / 確認 / 完了が分かれる。CDN の読み込みはそのまま、x-data などの `{…}` は標準テンプレートでモジュールの中に入れるならエスケープが要る | ― |
| 4. 割り当て | お知らせ = カテゴリーのエントリー、トップのお知らせ = エントリーの一覧、サイト名 = ブログ名、キャッチコピーと SNS = ブログのフィールド、メインビジュアルと紹介文 = モジュール ID のフィールド、お問い合わせ = フォーム、サービスのページ = 静的なまま | 標準版 Step 1・3、Twig 版第 4 回 |
| 5. テーマ | 一式を `themes/<名前>/` に置き、トップを `_top.html`（Twig 版は `.twig`）にする。管理ボックスと管理用の読み込みを最初に入れる。ヘッダーと横のナビゲーションをインクルードに分け、トップと下層の違いをタッチモジュールで出し分ける | 標準版 Step 1「テーマとして設定します」・Step 3「ヘッダー・フッターを共通化」、Twig 版第 3 回 |
| 6. 置き換え | トップのお知らせ一覧 → お知らせの詳細 → お知らせの一覧（サムネイル・ページャー）→ フォーム → ヘッダー・フッター → メインビジュアル。置き換えた後は、元の詳細ページと 2 ページ目のファイルをテーマから消す | 標準版 Step 1〜3、Twig 版第 4〜6 回 |
| 7. 管理画面 | カテゴリー（お知らせ）、モジュール ID（トップの一覧・一覧ページ・詳細、メインビジュアル）、フォーム ID、ブログのフィールドの値、サンプルの記事 | 各回の「管理画面でモジュール ID を作成」、Twig 版第 7 回のサンプルデータ |
| 8. 確認 | トップ → 一覧 → 詳細の順に、件数・日付・カテゴリー・ページャー・本文・`<title>`・管理ボックスを確かめる。ログアウトしても見る | Twig 版第 7 回の確認の表 |

チュートリアルのサンプルデータはエントリーのエクスポート・インポートの zip として配布されている。利用者が管理画面で取り込む（先にお知らせのカテゴリーが要る）。
